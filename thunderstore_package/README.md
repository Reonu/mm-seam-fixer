# Seam Fixer for Majora's Mask Recompiled

Fixes various seams and other graphical oversights in the game. This will be updated to fix more stuff over time.

Current list of fixes:
- Seam in the South Clock Town ramp
- Swamp Volcano clipping into the nearby trees in Termina Field
- Bonus: The unused cleared Swamp Volcano is now used after you beat Woodfall Temple

Thanks to Wiseguy for providing guidance.
